# 《熵》配樂需求規格（臨時）

交給作曲者或生成工具的規格。畫面會依你最後交來的音樂重新對齊，所以下面的時間是**目標**，不是硬性約束。
只有兩段靜默和總長比較重要，請盡量遵守。

## 基本參數

| 項目 | 規格 |
|---|---|
| 總長 | **4:00.000**（最後一個音在 3:57 響起，衰減到 3:58.67；之後 1.33 s 靜音） |
| 速度 | 72 BPM，4/4，固定速度（不要 rubato；需要的話只在第三幕內部微調） |
| 延長記號 | 2:26.667–2:28.667 完全數位靜音 2.000 s，之後在 2:28.667 重新起拍 |
| 交付 | WAV 48 kHz / 24-bit 立體聲；另附分軌 stem（八音盒/玻璃琴、預備鋼琴+大提琴、太鼓、二胡+弦樂、合唱） |
| 響度 | 整合 −16 LUFS 左右，真峰值 ≤ −1 dBTP；太鼓重擊保留動態，不要壓 |

## 主旋律（貫穿三幕）

- 8 小節，4+4 樂句；建議 D 多利亞調式（或 A 小調），音域能讓八音盒、二胡、合唱都唱得了。
- **第三級音是「那個音」**：第二幕第一個走音的就是它（先低 30 cents，之後愈走愈遠到約 −70 cents）。
  尾聲的八音盒重奏時其他音都調準了，**只有它仍然低約 30 cents**。這是視覺伏筆（種子六角）在聲音上的對應，請務必保留。
- 第一幕的旋律音盡量清楚、一音一音：雪花每個生長步驟會對在音符上。

## 必須對齊的點（畫面卡點）

完整清單在 `beatmap.json` 的 `hits`。最重要的是：
`0:03.333` 第一個音 · `1:20.000` 第一個走音 · `1:46.667` 抽空 · `1:50.000` 重擊 · `2:26.667–2:28.667` 靜默 ·
`2:28.667` 二胡 · `3:32.000` 高潮 · `3:57.000` 最後一個音。

如果作曲時這些點需要移動，沒關係，直接移。我會分析成品，讓畫面跟著音樂走。
